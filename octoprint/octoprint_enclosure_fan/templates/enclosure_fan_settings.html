Enclosure fan control (C3)

The mDNS name enclosure-fan-control.local survives the board taking a new DHCP lease. A plain IP address works too, and is the fallback where mDNS is blocked on the network.
8082 is the board's status/PID API and is the only port that reports whether a CYD is linked. 8080 is the OTA endpoint and 8081 is the CYD's machine channel — do not use either here.
The shared secret from the firmware's ENC_API_TOKEN, in include/enclosure_api.h. The board requires HTTP Basic auth with the username Enclosure and this as the password; the username is part of the credential and is fixed by the plugin.

Stored in OctoPrint's config.yaml, which is not in version control. Leave it empty only on a network where you have chosen to disable auth on the board.
Off freezes the tab on the last known values. Useful when you are debugging something else on the network and do not want the traffic.
