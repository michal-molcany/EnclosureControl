Enclosure fan control (C3)

Live state, PID tuning and manual control for the C3 board. Changes take effect immediately - no restart is needed. The tab is called Enclosure-Fan-Control in the navigation bar.

The board's IP address, e.g. 10.201.93.245, or its mDNS name enclosure-fan-control.local. The name survives the board taking a new DHCP lease; the IP does not, but it works where mDNS is blocked.
8082. That is the board's status/PID API, and the only port that reports whether a CYD is linked.
8081 will not work here - it is the CYD's machine channel and uses a different username. 8080 is the firmware upload page. Both exist on the board, so a wrong port looks like a rejected password rather than a wrong address; Test connection below says which it is.
The shared secret from the firmware's ENC_API_TOKEN, in include/enclosure_api.h. The board wants HTTP Basic auth with the username Enclosure and this value as the password; the username is fixed by the plugin.

Leave this blank to keep the token that is already saved. It is stored in OctoPrint's config.yaml (not in version control) and is never sent back to the browser, so an empty box after reloading the page means "a token is set", not "no token".
Off freezes the tab on the last known values. Useful when you are debugging something else on the network and do not want the traffic.
Probes the address, port and token as typed above, including a token you have not saved yet, and reports exactly what the board said. This is the quickest way to tell a wrong port from a wrong token.
